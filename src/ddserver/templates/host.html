Go to Internet → Permit Access → DynDNS, enable Use DynDNS, choose a custom provider and use these settings: 

Update URL:  {{ update_url }}?hostname=<domain>&myip=<ipaddr>,<ip6addr>
Domain name: {{ fqdn }}

The FRITZ!Box fills in the placeholders. Keep them as they are.

Install luci-app-ddns and go to Services → Dynamic DNS, or install ddns-scripts and add this to /etc/config/ddns: 

config service 'ddserver_ipv4'
	option enabled '1'
	option update_url '{{ url_with_login }}?hostname=[DOMAIN]&myip=[IP]'
	option lookup_host '{{ fqdn }}'
	option domain '{{ fqdn }}'
	option username '{{ username }}'
	option password '<host password>'
	option interface 'wan'
	option ip_source 'network'
	option ip_network 'wan'
{%- if request.scheme == 'https' %}
	option use_https '1'
	option cacert '/etc/ssl/certs/ca-certificates.crt'
{%- endif %}

For IPv6, add a second section with option use_ipv6 '1' and wan6 as interface and network. {% if request.scheme == 'https' %} HTTPS needs a download tool with TLS support and the package ca-bundle. {% endif %}

If your router has no fields for username and password, put them into the URL. Special characters in the password must be URL-encoded.
